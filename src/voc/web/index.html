Complaint labels: LLM against TF-IDF

CFPB complaints, July 2026. An LLM labels each complaint by product and quotes its evidence. A script checks the quote. Failures go to quarantine with a reason.

The verdict comes from the single logged run of the frozen test set. The panels after it are tuning figures from the development set.

What is being labelled

Each complaint is a consumer's own description of a problem. The label is the product the complaint is about: one of the CFPB's 11 products.

  • Checking or savings account
  • Credit card
  • Credit reporting or other personal consumer reports
  • Debt collection
  • Debt or credit management
  • Money transfer, virtual currency, or money service
  • Mortgage
  • Payday loan, title loan, personal loan, or advance loan
  • Prepaid card
  • Student loan
  • Vehicle loan or lease
The AI's label
An LLM picks a product and copies the sentence that shows why. A script checks the sentence is really in the complaint. If not, the complaint waits in quarantine for a person. (LLM, claude-haiku-5-5)
The word-based model's suggestion
A simple model that learned which words go with each product from 7,024 other complaints. It is the comparison the AI must beat. (TF-IDF)
The consumer's own choice
The product the consumer picked when filing. It is the answer key for scoring, and it is never shown to the AI. (recorded product)

Review and browse: the development set

These screens use the development set (370 complaints). The test set stays sealed: its text and its consumer's choices are read only by the one scored run (B17), and review never touches its results (B20).
